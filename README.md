# IPL Matches Analysis Project


## Project Overview
A sample IPL 2024 Matches Analysis project Developed using Python and Pandas.

### Objectives
* Load IPL2024 matches dataset
* Display match records
* calculate team-wise total wins
* Filter matches by team
* Toss winner by team
### Technologies & Tools used
* programming language: python
* Library: pandas (for data loading,filtering,and aggregation)
* Environment: Google Colab

### Dataset
* File: ipl2024 matches.csv
* Formate: CSV(Comma-Separated Values)
* Content: ipl 2024 matches records, including Columns such as team, toss, winner, player of the match.

### Features
* Overall match overview (total matches, seasons, cities, venues).
* Team analysis (matches played, wins, and win percentage).
* Toss analysis (toss decisions, toss winners, and toss winner/match winner comparison).
* Player analysis (top Player of the Match awards).
* Venue analysis (most-used venues and city-wise match counts).
* Season analysis (match count and team with the most wins in each season).
* Head-to-head analysis between two teams.
* Search team details and season-wise performance.
